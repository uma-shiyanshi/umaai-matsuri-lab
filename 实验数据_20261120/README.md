# 赛马娘 umaai-matsuri 实验数据归档（2026-11-20）

本目录归档 2026-11-11 ~ 11-19 期间的全部实验交付物，来自 `uma-shiyanshi/umaai-matsuri-lab` 本地沙箱计算。
计算环境：v0.1.7 引擎（`--search-n 128` 搜索档），默认马娘 `uma=100101` = [特别梦想家]特别周，本体加成 `速0/耐20/力0/根0/智10`。

## 目录结构

- `报告/` — 各阶段实验报告与参数说明（GA 权重重扫、双智参数全集、搜索档 GA 高 PT 迭代、方差分析、改动说明、仓库地址对照）
- `表格/` — 全部跑局汇总总表、1426 对智卡遍历表、评分/PT 差距表（xlsx + md + txt），均按 PT 或评分降序、含五维分列与马娘加成列
- `实验资产/` — GA 冠军配置片段、复核/验收 jsonl、1426 对原始 CSV、搜索档 ptfavor 梯度配置与各档 200 局逐局明细、双智参数合集

## 关键口径与结论

- **双智高 PT 冠军**（搜索档 GA）：PT 均值 12929.5、评分 80568、单局峰值 13877；起点 PT 12643.2。配对 t 检验 PT 11.66、评分 3.04。PT>13000 为 89 vs 31 局。
- **1426 对 SSR 智卡遍历**（速303114/耐303244/力303224/友303234 固定，两智卡位遍历）：PT 第一 = 青春永驻+成田白仁 12058.3；评分第一 = 成田白仁+爱慕律动 80389.3。
- **搜索档 ptfavor 梯度**（每档 200 局）：均值 PT 在 ptf=8 达峰 12625，之后平台期；评分在 ptf=1.54 最高 83151。
- **方差分析**：评分 sd 2575~3660（差 1.42 倍，p≈6e-55），与评分强相关 r=-0.708；PT sd 恒定 306~342（剧本+种子固有噪声，换卡/调旋钮均消不掉）。
- **小样本假象**：GA 单代 best 曾出现 +25355/+50065 虚高，经 200 局 recheck 否决；复核大样本比换强卡更可靠。
